# Рацион — семейный конструктор питания (MVP)

Статический сайт без сборки и сервера. Откройте `index.html` в браузере или опубликуйте файлы на GitHub Pages.

## GitHub Pages
1. Создайте публичный репозиторий GitHub.
2. Загрузите в корень `index.html` и `app.js`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Откройте URL, который появится в разделе Pages (обычно через несколько минут).

## Как пользоваться
- Найдите продукт и нажмите «Добавить».
- Для каждой позиции укажите граммы взрослому, граммы ребёнку и число дней в неделю (0–7).
- Значения показаны как среднесуточные, вычисленные из недельного плана.
- Сохраняйте варианты; дублируйте их для сравнения.
- Данные сохраняются в localStorage только на текущем устройстве. Для переноса используйте экспорт и импорт JSON.

## Важные ограничения
- Данные на 100 г ориентировочные; для некоторых веществ отсутствуют надёжные значения, они не учитываются, а не считаются нулём.
- Приготовленные и сухие продукты — разные позиции; сверяйте состояние в названии.
- Для продуктов в каталоге нет учёта конкретных брендов, потерь при готовке, добавленной соли и добавок.
- Целевые калории и макронутриенты — рабочие ориентиры, не медицинские предписания. Детская потребность индивидуальна и зависит от роста и нагрузок.
- Недельное среднее не означает, что можно компенсировать любой дефицит произвольным избытком в один день.
- При частичном покрытии базы показатели микронутриентов могут быть занижены. Не используйте их для диагностики или назначения препаратов.
